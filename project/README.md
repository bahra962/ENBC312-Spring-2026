# Car Rental Management System

## Description
This project is a Car Rental Management System. It allows users to manage vehicles using a simple menu system.

## Features
- Register a vehicle
- Deregister a vehicle
- Rent a vehicle
- Return a vehicle
- List all vehicles
- Sort vehicles by name
- Sort vehicles by rent start date

## OOP Concepts Used
- Inheritance: Base class Car and derived classes (Sedan, SUV, Truck, etc.)
- Polymorphism: Virtual function display() is used and overridden in child classes

## How to Run
1. Compile the program:
   g++ main.cpp -o carRental

2. Run the program:
   ./carRental
